# Auditorías de seguridad

Memoria del agente [`security-auditor`](../../.claude/agents/security-auditor.md). La escribe solo ese agente.

- **Hallazgos:** id `SEC-NNN` correlativo; severidad `crítica`, `alta`, `media`, `baja` o `info`; estado `abierto`, `en-spec`, `aceptado` o `cerrado`.
- Un hallazgo `aceptado` no se reporta como nuevo; solo se reabre si cambia la condición que lo justifica.
- El código y la base de datos mandan sobre este archivo.
